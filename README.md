# noashpaz-preview

پیش‌نمایش ایستای فارسی سایت **نوآشپز** (noindex، فقط برای بازبینی).

- نشانی: https://mohammadi77.github.io/noashpaz-preview/
- این مخزن خروجی ساخته‌شدهٔ `npm run build:preview` از مخزن اصلی است؛ دستی ویرایش نکنید.
- موتورهای جست‌وجو: `noindex, nofollow` و `robots.txt` با `Disallow: /`.
